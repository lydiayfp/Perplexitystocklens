# Stock Analyzer

Single-page starter for analyzing stocks, ETFs, Singapore listed securities, and unit trusts using published financial sources.

## Files
- `index.html` - UI shell.
- `app.js` - client-side logic and chart rendering.
- `data/sample.json` - sample payload.

## Notes
- Designed for offline-first use with local JSON caches.
- Replace sample data with published-source adapters for live price and fundamentals ingestion.
